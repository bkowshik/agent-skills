# Quickstart: Fix README Install Command

## What to change

Edit `README.md` at the repository root. Add an **Installation** section between the repo description line and the `## Skills` section.

## The change

Add this section to README.md:

```markdown
## Installation

```sh
npx skills add bkowshik/git-skills
```

## Verification

1. Read the rendered README on GitHub
2. Copy the install command
3. Run it in a terminal with Node.js installed
4. Confirm the skill installs successfully without errors
